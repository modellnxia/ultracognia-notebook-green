Testador de funcionalidades

Interface local para testar os endpoints de report_service.py sem precisar de curl. Requer a API rodando (uvicorn main:app) com ENV=local no .env.

Conexão

1. Preparar notebook POST /report/prepare-notebook

Busca todo o histórico de conversas do usuário e cria (ou reaproveita, se já feito hoje) um notebook no NotebookLM.

2. Gerar relatório POST /report/generate

Gera o relatório em Markdown de um notebook já preparado (use o notebook_id retornado no passo 1). Pode levar alguns minutos.

O relatório aparece aqui, formatado, depois de gerado.

3. Criar slides POST /report/create-slides

Gera o slide deck (PDF) de um notebook já preparado. Pode levar alguns minutos.

O PDF aparece aqui depois de gerado.
